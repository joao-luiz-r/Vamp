VAMP CHARACTER SHEET - PORTABLE DEPLOY
========================================

Esta pasta contem a aplicacao completa (Backend + Frontend).

COMO RODAR:
1. Clique duas vezes em 'Rodar_App.bat'.
2. O navegador abrira automaticamente em http://localhost:5000.
3. Se o navegador nao abrir, acesse manualmente o endereco informado.

REQUISITOS:
- Windows 64-bit.
- .NET 8 Runtime (instale de https://dotnet.microsoft.com/download/dotnet/8.0 se nao funcionar).

NOTAS:
- Nao mova os arquivos para fora desta pasta, eles dependem uns dos outros.
- Os personagens sao salvos localmente no arquivo 'characters.json'.
